# Matrimonial Eligibility Checker

A Java console application that checks eligibility rules step by step. The user enters details one by one, and the program stops at the first rule that does not match.

## Description
This is a beginner Java project that practises user input, conditions, and data types. The program asks for name, assets, salary, age, height, weight, and siblings. After each step it shows whether the user can continue or does not match the criteria.

## Features
- Takes user input from the console using Scanner
- Checks assets and salary, age, height, and weight against fixed rules
- Uses if-else conditions to check each rule in order
- Shows a clear message at every step
- Uses Java data types: String, int, float, double, and boolean

## Eligibility Rules
| Detail | Rule |
|--------|------|
| Assets | 5,00,00,000 or more |
| Salary | 25,00,000 or more |
| Age | 26 to 30 |
| Height | 5.7 to 6.1 feet |
| Weight | 65 to 75 kg |

## Technologies Used
- Core Java
- Eclipse IDE

## How to Run
1. Clone or download this repository
2. Open it in Eclipse
3. Run `MatrimonialApp.java` as a Java Application
4. Enter the details when the console asks
